# HR Analytics Dashboard — Power BI

A Power BI report template that explores employee attrition and workforce patterns using a sample HR dataset.

## What is in this repository

| File | Purpose |
|---|---|
| `HR Analytics Dashboard.pbit` | Power BI template containing the report page, data model and the `AttritionRate` DAX measure |
| `HR_Analytics.csv` | Sample dataset: 1,480 rows and 38 columns, including `Attrition`, `Department`, `JobRole`, `MonthlyIncome`, `OverTime`, `JobSatisfaction`, `WorkLifeBalance` and `YearsAtCompany` |
| `BG12 (1).jpg` | Background image used by the report page |

## Report contents

The template contains one report page with six KPI cards, a donut chart, a column chart, two clustered bar charts, an area chart, a treemap, a pivot table and a slicer. The data model has one table and one DAX measure, `AttritionRate`.

## Tools

- Power BI Desktop
- CSV data source
- DAX

## How to open it

1. Download or clone this repository.
2. Open `HR Analytics Dashboard.pbit` in Power BI Desktop.
3. If Power BI cannot find the data file, point the data source at your local copy of `HR_Analytics.csv` (Home → Transform data → Data source settings).

These steps follow standard Power BI behaviour and have not been tested against this specific template.

## Data disclaimer

The dataset used in this project is sample or publicly available data. No sensitive or confidential information is intended to be included.
